## Readme file for the World WebGL experiences

Writing this to track changes as I migrate to WebGPU and TSL. I'm going to have a two-tier approach:
1. First, write a complimentary tsl world experience setup following the same architecture
2. Slowly migrate across experiences to TSL as needed. Some won't need any migrations apart from pointing at WEBgpu renderer instead of webgl.

Fortunately, Webgpu class supports both currently. 

See [https://threejs.org/tsl/#welcome]
